Invite Sender

Sends a personalised WhatsApp message to each invitee from your own WhatsApp. One tap opens the chat with the message typed; you press Send. Nothing here is uploaded anywhere — the list lives only in this browser.

1 · The list

Any format works: name, number · number alone · tab-separated from Excel. Iraqi numbers are converted to +964. Duplicates are removed.

2 · The message

Keep the person's name and some real text in it. A bare link sent to many strangers is what gets a WhatsApp account flagged.
